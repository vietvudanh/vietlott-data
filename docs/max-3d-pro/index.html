Dataset Overview & Record Schema

Result Schema: result is a JSON object with the same 4 prize tier keys as Max 3D: "Giải Đặc biệt" (2 triplets), "Giải Nhất" (4 triplets), "Giải Nhì" (6 triplets), and "Giải ba" (8 triplets).

Technical Notes: Max 3D Pro is drawn on Tuesday, Thursday, and Saturday, complementing Max 3D (Monday, Wednesday, Friday). Leading zeros are preserved as 3-digit strings.

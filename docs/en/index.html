Crawler & Tooling: Go (Recommended) vs Python

Go Crawler (Recommended): Production crawling and rendering run on the standalone Go binary (bin/vietlott-crawler), which is ~1.7× faster and uses <2 MB RAM. Because Vietlott geo-blocks non-Vietnam IP addresses, crawling runs on a local runner in Vietnam and commits daily updates to GitHub.

Python Package: The vietlott-data package on PyPI provides Python schemas and legacy CLI commands (vietlott-crawl, vietlott-missing) for Python workflows.

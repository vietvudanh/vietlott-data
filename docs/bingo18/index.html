Dataset Overview & Record Schema

Draw Schedule: Daily every 10 minutes (06:00–21:53 ICT)

Result Schema: result is an array of 3 integers (each 1–6, representing three dice/numbers), accompanied by total (integer sum 3–18), large_small ("Nhỏ", "Hòa", or "Lớn"), and process_time.

Technical Notes: With 3 independent numbers from 1 to 6, there are 6³ = 216 possible ordered outcomes per draw. Use polars.scan_ndjson('data/bingo18.jsonl') for fast aggregations over all 97,000+ records.

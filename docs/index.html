Tính năng Nổi bật

Quy trình tự động hóa thu thập và xử lý dữ liệu mạnh mẽ

Tự động Hóa Định kỳ

Bộ thu thập chạy định kỳ theo lịch trình chính thức của Vietlott, cập nhật kết quả mới nhất ngay sau mỗi kỳ quay.

Định dạng NDJSON Chuẩn

Dữ liệu được lưu trữ dạng Newline Delimited JSON, tối ưu cho xử lý stream, append liên tục và tương thích Polars/Pandas.

Giao diện CLI Tiện lợi

Cung cấp sẵn các lệnh CLI vietlott-crawl và vietlott-missing để dễ dàng cào dữ liệu mới hoặc bù đắp các kỳ thiếu.

Hướng dẫn Sử dụng

Cài đặt & Giao diện Dòng lệnh

Tích hợp vào project Python hoặc chạy trực tiếp bằng công cụ dòng lệnh

Cài đặt thư viện

Cài đặt thông qua uv (khuyến nghị) hoặc pip:

bash 
# Khuyến nghị sử dụng uv
$uv add vietlott-data

# Hoặc sử dụng pip thông thường
$pip install vietlott-data

Sử dụng CLI Crawler

Thu thập dữ liệu các sản phẩm xổ số theo tên:

bash 
# Thu thập kỳ mới nhất cho Power 6/55
$vietlott-crawl power_655

# Thu thập dữ liệu Keno
$vietlott-crawl keno

# Tìm kiếm và bù đắp các kỳ mở thưởng còn thiếu
$vietlott-missing power_655

Tuyên bố Miễn trừ Trách nhiệm

Dự án này chỉ dành cho mục đích giáo dục, nghiên cứu dữ liệu và phân tích thống kê. Kết quả xổ số là hoàn toàn ngẫu nhiên và không thể dự đoán chính xác. Dự án không cung cấp bất kỳ lời khuyên đánh bạc hay bảo đảm trúng thưởng nào.

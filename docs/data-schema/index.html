Technical Specification

NDJSON Data Schema Reference

Exact field definitions, data types, and winning-number semantics for all seven Vietlott lottery datasets in data/*.jsonl.

Common Record Fields

Field Type Description
datestring (YYYY-MM-DD)Official draw date in Vietnam time (ICT, UTC+7).
idstringZero-padded draw identifier (5 digits for Power/Max3D, 7 digits for Bingo18, # + 7 digits for Keno).
resultarray<int> | objectWinning numbers for the draw. Structure depends on the specific game (detailed below).
process_timestring (ISO-8601)Timestamp when the record was crawled/processed (present on Power 6/55, Mega 6/45, Power 5/35, Bingo18).

Per-Product result Semantics

Product File result Type Exact Semantics & Bonus Number Rules
Power 6/55 data/power655.jsonl int[7] First 6 elements (result[0:6]) are main numbers (1–55). The 7th element (result[6]) is the special/bonus number (Jackpot 2).
Mega 6/45 data/power645.jsonl int[6] 6 main winning numbers (1–45). Mega 6/45 has NO bonus/special number. All 6 elements are main numbers.
Power 5/35 data/power535.jsonl int[6] First 5 elements (result[0:5]) are main numbers (1–35). The 6th element (result[5]) is the special number.
Keno data/keno.jsonl int[20] 20 winning numbers drawn from 1–80. Also includes top-level big_small and odd_even strings.
Max 3D data/3d.jsonl map<string, string[]> Object with 4 prize keys: "Giải Đặc biệt" (2 triplets), "Giải Nhất" (4), "Giải Nhì" (6), "Giải ba" (8) — 20 zero-padded 3-digit strings total.
Max 3D Pro data/3d_pro.jsonl map<string, string[]> Same 4 prize keys and 20 3-digit string triplets as Max 3D.
Bingo18 data/bingo18.jsonl int[3] 3 numbers from 1–6, accompanied by top-level total (sum 3–18) and large_small ("Nhỏ", "Hòa", "Lớn").

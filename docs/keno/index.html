Dataset Overview & Record Schema

Draw Schedule: Daily every 10 minutes (06:00–21:50 ICT, up to 96 draws/day)

Result Schema: result is an array of 20 integers drawn from 1 to 80. Each record also includes big_small (Chẵn/Lẻ/Hòa parity or Big/Small summary as labeled on Vietlott) and odd_even, and id is prefixed with # (e.g., #0301098).

Technical Notes: Because Keno draws every 10 minutes, data/keno.jsonl is the largest file (~14 MB, 90,000+ records). Use streaming or columnar readers like polars.scan_ndjson('data/keno.jsonl') rather than loading the entire file into a list of dicts.

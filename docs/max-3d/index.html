Dataset Overview & Record Schema

Draw Schedule: Monday, Wednesday, Friday (18:00–18:30 ICT)

Result Schema: result is a JSON object mapping 4 prize tier keys to arrays of 3-digit strings ("000"–"999"): "Giải Đặc biệt" (2 triplets), "Giải Nhất" (4 triplets), "Giải Nhì" (6 triplets), and "Giải ba" (8 triplets) — 20 triplets total per draw.

Technical Notes: Triplets are stored as zero-padded 3-character strings (e.g., "005") to preserve leading zeros. In Polars or Pandas, unnest or normalize the result struct/dict to analyze specific prize tiers.

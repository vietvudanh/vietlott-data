Python, Polars & Pandas Examples

Practical recipes for loading Vietlott NDJSON files, separating main vs. bonus numbers, streaming large Keno datasets, and detecting missing draw IDs.

1. Load Power 6/55 & Separate Main vs. Bonus Numbers (Polars)

In Power 6/55, result has 7 elements (6 main numbers + 1 bonus number). In Mega 6/45, all 6 elements are main numbers.

python (polars)
import polars as pl

df = pl.read_ndjson("https://raw.githubusercontent.com/vietvudanh/vietlott-data/main/data/power655.jsonl")
df = df.with_columns([
    pl.col("date").str.to_date(),
    pl.col("result").list.slice(0, 6).alias("main_numbers"),
    pl.col("result").list.get(6).alias("bonus_number"),
])

# Main number frequency (excluding the 7th bonus ball)
main_freq = (
    df.explode("main_numbers")
    .group_by("main_numbers")
    .len()
    .sort("len", descending=True)
)
print(main_freq.head(10))

2. Stream High-Volume Keno Data Without Memory Spikes

Keno has over 90,000 draws. Use Polars lazy scanning (pl.scan_ndjson) or DuckDB to filter and aggregate in streaming fashion:

python (polars lazy scan)
import polars as pl

keno_lazy = pl.scan_ndjson("data/keno.jsonl")
recent_freq = (
    keno_lazy
    .filter(pl.col("date") >= "2026-01-01")
    .explode("result")
    .group_by("result")
    .len()
    .sort("len", descending=True)
    .collect()
)
print(recent_freq.head(10))

3. Analyze Mega 6/45 with Pandas

python (pandas)
import pandas as pd

url = "https://raw.githubusercontent.com/vietvudanh/vietlott-data/main/data/power645.jsonl"
df = pd.read_json(url, lines=True)
df["date"] = pd.to_datetime(df["date"])

# Mega 6/45 has 6 main numbers and no bonus number
freq = df.explode("result")["result"].value_counts()
print(freq.head(10))

4. Detect Missing Draw IDs

python
import polars as pl

df = pl.read_ndjson("data/power655.jsonl")
ids = set(df["id"].str.strip_chars("#").cast(pl.Int64).to_list())
expected = set(range(min(ids), max(ids) + 1))
missing = sorted(expected - ids)
print(f"Missing draws: {missing}")
